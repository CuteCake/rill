# Rill

Explore MLIR and Caffe prototxt as interactive dataflow graphs inside VS Code.

Select one or more IR files in Explorer and choose **Open in Rill**. Multiple files open as a naturally sorted pass timeline. From the Command Palette, **Rill: Open in Rill** opens a snapshot of the current IR buffer, including unsaved edits, or prompts for files.

Use **Open** inside the viewer to load another series or a saved Rill session. For source, examples, and dialect profile documentation, visit the [Rill project](https://github.com/CuteCake/rill).
